# 팔라스 관측실 디자인 기준

## 화면

- 전역 탐색의 이름과 순서는 수업지도안, 수업자료, 시뮬레이터다. 지도안의 각 활동은 해당 수업자료 또는 분석 단계로 연결된다. 실습의 주기와 탐구 기록은 화면을 바꾸어도 유지한다.
- 각 화면에서 먼저 읽을 대상을 하나 정한다. 수업자료는 실물 이미지와 본문, 분석은 그래프와 연결된 조작부, 탐구 노트는 학생이 남긴 증거에 집중한다.
- 카드 반복, 둥근 배지, 장식용 아이콘, 그라데이션, 독립된 수치 타일을 추가하지 않는다. 여백과 수평선으로 정보를 구분한다. 강조색은 실제 선택과 행동에만 쓴다.
- 조작과 설명을 맞춘다. 그래프는 축을 고정하고 선택한 관측점의 실제 JD와 강도를 표시한다. 회전을 조절하면 모형과 광도곡선의 위상 표시가 함께 움직인다. 키보드와 좁은 화면에서도 같은 작업을 할 수 있어야 한다.
- 설명은 필요할 때 펼친다. 기본 화면에는 질문 하나와 다음 행동이 보이게 한다. 전문 용어는 처음 쓰는 자리에서 짧게 정의한다.

## 발표 슬라이드

- 상단에 같은 위치와 순서로 구분 띠를 둔다. 현재 장만 강조한다. 발표 본문에는 한 가지 근거와 핵심 문장만 남기고 설명은 발표자 노트로 옮긴다.
- 실제 관측 사진은 대상과 관측 기관을 캡션에 적는다. 재계산한 그래프는 자료 출처를 표시한다. 교실용 모형은 예측 표시를 유지한다.
- 발표자료, 지도안, 학생 화면에서 1차시 순서를 일치시킨다. 소행성 역사, 실제 연구 사례, 학생의 자료 분석 순이다.
