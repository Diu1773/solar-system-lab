기획과 개발 기록

소행성 관측실을 만든 목적과 구조

태양계천문학 과제로 만든 2차시 탐구 수업 도구. 무엇을 하려고 만들었는지, 수업을 어떻게 짰는지, 어떤 자료와 도구를 썼는지, AI에게 무엇을 요청하고 어떻게 고쳤는지를 정리함.

1. 목적2. 기획과 구조3. 사용한 자료와 도구4. 요청과 교정5. 검증

1. 목적

출발점태양계천문학에 맞는 주제를 고민하다, 평소 궁금했던 소행성을 실제 관측 자료로 분석하는 수업 시뮬레이터를 만들고 싶었음
풀고 싶은 문제교과서에서 소행성은 사진과 정의로만 등장함. 망원경으로 점으로만 보이는 천체의 자전과 모양을 천문학자가 어떻게 알아냈는지, 학생이 실제 자료로 직접 따라가 볼 기회가 없음
시뮬레이터가 하는 일① 공개 관측 데이터베이스의 실제 측광 자료를 설치 없이 브라우저에서 다루게 함 ② 모양을 바꿔 돌려 보며 밝기 곡선이 만들어지는 과정을 보여 줌 ③ AI가 낸 분석 결과를 자료와 물리로 검증하게 함 ④ 학생의 추론을 탐사선 관측과 비교하게 함
탐구 질문1차시: 에로스의 밝기는 왜 몇 시간마다 변할까?
2차시: 에로스는 몇 시간마다 한 바퀴 돌고, 어떤 모양일까?

2. 기획과 구조

수업 구조: 수업자료(교사) ↔ 탐구 시뮬레이터(학생)

차시마다 교사가 넘기는 슬라이드 수업자료와 학생이 조작하는 탐구 시뮬레이터를 분리함. 슬라이드의 ‘▶ 탐구 시뮬레이터 ○단계’ 표시에서 학생 활동으로 넘어가고, 시뮬레이터 단계 끝의 ‘다음: 수업자료 ○○’에서 다시 돌아옴.

설계 원칙

  • 처음 생각 → 최종 답: 두 차시 모두 시작에 학생의 예상을 받고, 끝에서 최종 답과 나란히 놓아 생각의 변화를 확인함
  • 예측 먼저, 확인은 학생이: 가설별 밝기 곡선을 먼저 고른 뒤 모형을 돌려 곡선이 만들어지는 것을 보고, 예측과 같은지 학생이 판단함. 정답을 화면이 먼저 보여 주지 않음
  • 단계마다 목표·할 일·남길 것: 시뮬레이터의 각 단계 위에 표시해 학생이 무엇을 위해 무엇을 하는지 알게 함
  • 실제 자료만: 역사 인물·건물, 탐사선·망원경 사진, 측광 자료 모두 실제 자료. 모형 그림은 설명용으로 표시
  • 학습목표에서 벗어나는 활동은 넣지 않음: 망원경 영상의 구경 측광처럼 인지 부담이 큰 처리는 빼고, CSV 자료로 그래프를 읽는 데이터 리터러시에 집중

4. 요청과 교정

AI에게 말로 요청하고, 결과를 보며 고칠 점을 다시 지시하는 방식으로 진행함. 요청은 실제 대화의 요지를 정리한 것.

단계요청(요지)AI가 한 일판단과 교정
1“태양계천문학 주제로 AI를 활용한 데이터 분석 수업 2차시. 1차시는 소행성의 역사를 실제 그림·사진으로 다큐처럼, 그다음 천문학자 방식으로 자전주기와 밝기 곡선 모형 맞추기”첫 시안(팔라스 자료)요구와 맞지 않아 다시 시작
2(같은 요구로 재시작)DAMIT 자료 수집, 1975년 근접 관측 선택, 주기 탐색, 절반 주기 문제 발견, 실제 사진 수집문헌값과 대조, 절반 주기 문제를 AI 검증 활동으로 채택
3“흰 바탕으로, 글꼴도 바꿔 줘”디자인 전면 수정디자인 기준 확정
4“에로스가 아니라 소행성이 핵심. 누가, 무엇을 좋아했고, 무엇을 발견해 소행성이라 부르게 되었는지로”1781–1802 발견 이야기로 1차시 재구성학습목표를 ‘소행성과 발견의 역사’로 수정
5“교생실습 PPT처럼 수업자료는 슬라이드로, 그다음 시뮬레이터를 따로”수업자료와 탐구 시뮬레이터 분리직접 그린 도식 제거, 실제 이미지로 교체
6“개념 주입이 아니라 탐구 수업. 5E 같은 탐구 모형으로”5E 순서로 재배열과학 용어(측정·극대) 통일, 제목은 명사구
7중간발표 피드백: “실제 데이터 중심, 땅콩 모양 가설, AI 비교는 사례를 확실히, 단계마다 목표, 마무리 연결”땅콩 모양 모형, AI 사례 검증, 단계별 목표구경 측광은 학습목표에서 멀어 제외
8“탐구 질문은 역사 이야기에서 나오게. 처음 예상 → 마지막 답으로 비교. 실제 탐사선 영상으로”1901년 장면에서 탐구 질문, 처음 생각·최종 답 비교, NEAR·Dawn 자전 영상수업자료↔시뮬레이터 전환 표시 추가
9“누르면 바로 답을 알려 주는 식은 안 됨. 소행성이 도는 모습도 있어야”예측 후 모형을 돌리며 밝기 곡선이 그려지는 활동정답 자동 표시 제거, 판단은 학생이

요청문 예시

  • “1975년 1월 에로스 다섯 밤 자료로 주기를 2~8시간에서 탐색하고, 사인 곡선 하나로 맞추는 방법과 4차 푸리에 곡선으로 맞추는 방법의 결과를 비교해 줘.”
  • “NEAR가 정한 에로스 자전축으로 1975년 1월에 지구에서 본 시선 각을 계산해 줘.”
  • “Wikimedia Commons에서 피아치, 가우스, 올베르스, 허셜의 실제 초상과 탐사선 사진을 찾아 라이선스와 함께 정리해 줘. 생성 이미지는 쓰지 마.”
  • “시뮬레이터 단계마다 목표, 할 일, 남길 것을 보여 주고, 마지막에 처음 생각과 최종 답을 나란히 보여 줘.”

5. 검증

  • 학생 활동 예시 주기 5.266시간과 NEAR 측정 5.270시간 대조
  • AI 사례 코드를 실제로 실행해 2.632시간이 나오는 것 확인
  • NEAR 자전 영상의 촬영 시각·경도로 약 5.16시간 계산(탐사선 궤도 운동으로 공식값과 차이)
  • 성취기준 문장을 2022 개정 과학과 교육과정 원문과 대조
  • 역사 서술의 연도·인물, 이미지 라이선스 확인. 확인되지 않은 세부는 서술에서 제외
