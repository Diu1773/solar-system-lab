개발 기록

AI 바이브 코딩으로 만든 과정

원하는 것을 말로 설명하고, AI 코딩 에이전트가 자료 수집·계산·화면 구현을 맡고, 개발자가 결과를 보며 고칠 점을 다시 말로 지시하는 방식으로 만들었습니다. 아래 요청문은 실제 대화의 요지를 정리한 것입니다.

사용한 도구와 역할

AI 코딩 에이전트Claude Code(Anthropic), Codex(OpenAI) · 파일을 읽고 고치고 실행까지 하는 에이전트형 도구
AI가 맡은 일DAMIT 관측 자료 수집과 정리, 주기·모형 계산, 실제 이미지 검색과 라이선스 기록, 웹 화면·그래프·발표자료 구현
개발자가 맡은 일주제와 수업 흐름 결정, 학습목표 설정, 화면·문구 검토와 교정 지시, AI가 낸 수치와 사실을 원문과 대조

개발 흐름

단계개발자의 요청(요지)AI가 한 일개발자의 판단과 교정
1“AI를 활용해 태양계천문학 주제로 데이터 분석 수업 2차시를 만들어 줘. 1차시는 소행성의 역사를 실제 그림·사진으로 다큐처럼, 그다음 실제 천문학자 방식으로 자전주기를 분석하고 밝기 프로파일에 모형을 맞춰 보게.”첫 시안(팔라스 자료)을 만들었으나 화면과 문구가 요구와 맞지 않음시안을 쓰지 않기로 하고 다시 시작
2(같은 요구를 다시 전달)DAMIT에서 에로스 광도곡선 118개를 내려받아 정리, 1975년 1월 근접 관측 다섯 밤 선택, 주기 탐색, 흔한 주기 분석이 절반 주기(2.63시간)를 고르는 문제 발견, 탐사선 자전축으로 시선 각 계산, Wikimedia Commons에서 실제 인물·탐사선 사진 수집수치를 문헌값(NEAR 5.270시간, 34.4×11.2×11.2 km)과 대조. 절반 주기 문제를 AI 검증 활동의 소재로 채택
3“어두운 화면과 명조체는 AI가 만든 티가 난다. 흰 바탕으로, 글꼴도 바꿔 줘.”흰 바탕, 글꼴 하나, 논문 그림 같은 그래프로 전면 수정디자인 기준 확정
4“에로스가 아니라 ‘소행성’이 핵심이다. 어느 해, 누가, 무엇을 좋아했고, 무엇을 발견해 소행성이라 부르게 되었는지로 이야기를 깔아 줘.”1781년 허셜부터 1802년 ‘asteroid’ 명명까지 발견 이야기로 1차시 재구성학습목표를 ‘소행성이 무엇인지와 발견의 역사’로 수정
5“수업자료는 교생실습 때 만든 PPT처럼 슬라이드로, 그다음에 시뮬레이터를 따로 두는 구조로.”차시마다 수업자료(슬라이드)와 탐구 시뮬레이터로 분리“직접 그린 도식 대신 실제 이미지를 써라”, “가설 비교 그래프가 정답을 먼저 보여 준다”를 지적해 고침
6“개념 빈칸을 채우는 주입식이 아니라 탐구 수업이다. 5E 같은 탐구 모형으로.”참여–탐색–설명–정교화–평가 순서로 슬라이드 재배열‘재다·꼭대기’ 같은 말을 ‘측정·극대’로, 제목은 명사구로 통일
7중간발표 피드백 반영: “실제 데이터 중심, 땅콩 모양 소행성 가설, AI 비교는 사례를 확실히, 시뮬레이터 단계마다 목표, 마무리와 활동의 연결”땅콩 모양 모형과 ‘예측 → 모형 확인’ 활동, 실제 실행한 AI 코드 사례와 4단계 검증 과제, 단계별 목표 막대, 탐구 질문에 답하는 마무리 추가구경 측광처럼 학습목표에서 벗어나는 활동은 넣지 않기로 결정

요청문 예시

  • “1975년 1월 에로스 다섯 밤 자료로 주기를 2~8시간에서 탐색하고, 사인 곡선 하나로 맞추는 방법과 4차 푸리에 곡선으로 맞추는 방법의 결과를 비교해 줘.”
  • “NEAR가 정한 에로스 자전축으로 1975년 1월과 1951년 10월에 지구에서 본 시선 각을 계산해 줘.”
  • “Wikimedia Commons에서 피아치, 가우스, 올베르스, 허셜의 실제 초상과 탐사선 사진을 찾아 라이선스와 함께 정리해 줘. 생성 이미지는 쓰지 마.”
  • “시뮬레이터 단계마다 목표, 할 일, 남길 것을 보여 주고, 마지막 단계에서 탐구 질문에 답하게 해 줘.”

검증한 것

  • 자전주기 5.266시간(학생 활동 예시)과 NEAR 측정 5.270시간 대조
  • AI 사례 코드를 실제로 실행해 2.632시간이 나오는지 확인
  • 성취기준 문장을 2022 개정 과학과 교육과정 원문과 대조
  • 역사 서술의 연도·인물과 이미지 라이선스 확인, 확인되지 않은 세부는 서술에서 제외
