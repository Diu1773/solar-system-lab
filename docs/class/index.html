LESSON 01

태양흑점 분석 활동

50분 · 지도안+활동지수업 세트 열기 ↗

날짜별 흑점의 이동으로 태양의 자전주기를 어떻게 추정할까?

  1. 영상에서 같은 흑점을 식별하고 5개 날짜의 위치와 사용 여부를 기록한다.
  2. 경도–시간 그래프의 기울기와 단위로 회합 자전주기를 추정한다.
  3. 가장자리 투영·좌표 보정·흑점 변화가 결과에 미치는 영향을 근거와 함께 설명한다.

제출물 5일 이상 측정표, 경도–시간 그래프, 단위가 있는 주기 계산, 근거와 오차를 포함한 결론

NASA SDO/HMI 연속광 JPG 10장
북쪽 위 방향 가정·교육용 원반 보정이며 정밀 WCS 분석이 아니다. 한 흑점의 짧은 기록으로 위도별 차등 자전을 입증할 수 없다.

LESSON 02

소행성 밝기 분석 활동

50분 · 지도안+활동지수업 세트 열기 ↗

소행성의 밝기 변화에서 어떤 자전주기가 관측을 잘 설명할까?

  1. 실제 측광의 대상·시각·상대 강도와 처리 방법을 설명한다.
  2. 세 개 이상의 시험 주기를 위상 그래프·잔차로 비교해 주기 후보를 선택한다.
  3. 관측 간격과 형상·반사율·시선의 모호성이 추론에 주는 한계를 설명한다.

제출물 세 주기 비교표, 위상 그래프, 선택 후보의 근거, 유일한 주기·모양을 확정하지 못하는 이유

DAMIT (2) Pallas, curve_id 26·27·28, 155점
오차 열이 없고 관측에 빈 시간이 있다. 최소 잔차 후보가 유일한 항성 주기·3D 모양을 확정하지 않는다.

LESSON 03

태양 스펙트럼 분석 활동

50분 · 지도안+활동지수업 세트 열기 ↗

태양빛의 흡수선에서 어떤 원소의 흔적을 찾을 수 있을까?

  1. 아틀라스의 파장 단위를 Å에서 nm로 변환하고 정규화 강도를 설명한다.
  2. 세 흡수선의 최소 표본 파장·깊이를 측정해 기준 파장과 비교한다.
  3. 원소 식별의 근거와 혼합선·정규화·분해능에 따른 한계를 설명한다.

제출물 세 선 측정표, 파장–강도 그래프, 기준 파장 비교, 원소 후보와 해석 한계

BASS2000 / Jungfraujoch Solar Atlas (Delbouille, Roland & Neven, 1973)
국소 정규화 자료로 절대 플럭스·온도를 복원하지 않는다. 최소 표본은 정밀 보정 선 중심이 아니다. 선 깊이는 함량에 단순 비례하지 않는다.

LESSON 04

행성 궤도 분석 활동

50분 · 지도안+활동지수업 세트 열기 ↗

공개 행성 자료의 장반경·공전주기는 케플러 법칙과 얼마나 맞을까?

  1. 기관의 장반경·주기 자료와 법칙으로 계산한 모형 결과를 구분한다.
  2. 같은 시간의 쓸고 간 면적과 네 행성의 T²/a³을 비교한다.
  3. 모형에 이미 들어 있는 법칙을 독립 관측 검증으로 해석하지 않고 자료의 근사를 설명한다.

제출물 네 행성 공개 자료·비율 계산표, T²–a³ 그래프, 같은 시간 면적 비교, 모형과 자료의 한계

JPL J2000 평균 궤도 요소와 Sidereal Orbital Period 표의 수성·금성·지구·화성
기관 자료는 관측을 바탕으로 정리한 값이며 원시 FITS가 아니다. 지구의 a·e는 지구–달 질량중심, 주기는 지구 값이다. 서로 다른 표의 근사·기준으로 작은 차이가 난다. 모형은 독립 관측 검증이 아니다.

1

실습 키트를 받고 폴더 열기

실습 키트 ZIP을 내려받아 압축을 풀고 starter 폴더를 Codex의 로컬 프로젝트로 엽니다. 실제 자료는 data/pallas-1971.csv, 설명은 SOURCE.txt입니다. 파일을 읽어 만드는 실습이므로 이 폴더가 연결되어 있는지 확인하세요.

starter/
├─ data/pallas-1971.csv 실제 관측 155점
├─ SOURCE.txt 대상·열·출처·가정
└─ START.txt 시작 요청문

기존 실습실을 수정하려면 ‘자료·공유’의 전체 소스 ZIP을 풀어 프로젝트를 열고 docs 안의 파일을 다룹니다. 로컬 프로젝트 공식 안내

2

만들기 전에 실제 자료부터 읽히기

아래 요청문을 복사해 보냅니다. Codex가 보여 준 행 수·열 이름·대상을 CSV와 SOURCE.txt에서 직접 대조합니다.

① 자료 확인 요청
이 폴더의 SOURCE.txt와 data/pallas-1971.csv를 읽어 줘.
대상, 관측 시기, 관측 회차별 점 수, 열 이름과 단위를 표로 정리해 줘.
JD는 빛 도달 시간 보정 값이고 intensity_relative는 상대 강도야.
절대등급·오차 열·FITS 영상이 이 CSV에 포함되어 있는지 구분해 줘.
아직 코드는 수정하지 말고, 값 두 행을 예시로 읽어 줘.

확인 기준: 팔라스, 1971년 11월 28–30일, curve_id 26·27·28, 합계 155점. 원본 숫자는 변형 없이 추출했습니다.

3

한 화면에서 작동하는 도구 요청하기

자료를 확인한 뒤 아래 요청문을 보냅니다. 생성된 index.html을 브라우저에서 열고 같은 자료가 보이는지 확인합니다.

② 첫 도구 만들기
data/pallas-1971.csv로 교육용 광도곡선 도구를 index.html 한 파일로 만들어 줘.
HTML·CSS·JavaScript만 쓰고 외부 라이브러리는 쓰지 마.
CSV는 파일 선택 버튼으로 사용자가 열게 해 줘. 원본 파일과 값은 수정하지 마.
실제 관측 시각 그래프와 위상 그래프를 전환하고 curve_id별로 색을 구분해 줘.
m = -2.5 log10(F), 위상 = frac[24(JD-JD0)/P]를 사용해 줘.
P는 시간 단위로 입력하며 7.2를 초기값으로, JD0는 전체 최소 JD로 해 줘.
위상 비교에는 회차별 평균 m을 뺀 상대 등급을 표시하고 등급 축은 밝은 쪽이 위로 오게 해 줘.
관측점 수, 출처와 처리 방법을 표시해 줘. 자동 주기 탐색과 3D 기능은 다음 단계로 두자.
완료 후 파일을 열어 보는 방법과 확인할 항목을 알려 줘.

CSV를 로컬에서 직접 여는 방식이라 서버나 API 키 없이 첫 도구를 만들 수 있습니다. 코드 생성 결과는 달라질 수 있으므로 아래 기준으로 확인하세요.

근거 있는 활동 설계
첨부한 강의계획서·교재 목차와 이 실습실의 활동을 비교해 줘.
원문에서 확인되는 단원과 학습 목표만 연결하고 해당 쪽이나 항목을 적어 줘.
태양 자전, FITS 측광, 팔라스 3D 모형 비교를 직접 연계와 확장 활동으로 구분해 줘.
한 활동을 골라 30분 수업 순서·탐구 질문·학생 제출물·평가 기준을 만들어 줘.
교재에 3D 형상 역산이 포함되어 있다고 임의로 쓰지 마.
확인할 수 없는 내용은 교수님 확인이 필요한 항목으로 남겨 줘.
