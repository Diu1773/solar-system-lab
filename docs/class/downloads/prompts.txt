1. 자료 먼저 확인
이 폴더의 SOURCE.txt와 data/pallas-1971.csv를 읽어 줘.
대상, 관측 시기, 관측 회차별 점 수, 열 이름과 단위를 표로 정리해 줘.
JD는 빛 도달 시간 보정 값이고 intensity_relative는 상대 강도야.
절대등급·오차 열·FITS 영상이 이 CSV에 포함되어 있는지 구분해 줘.
아직 코드는 수정하지 말고, 값 두 행을 예시로 읽어 줘.

2. 광도곡선 첫 도구 만들기
data/pallas-1971.csv로 교육용 광도곡선 도구를 index.html 한 파일로 만들어 줘.
HTML·CSS·JavaScript만 쓰고 외부 라이브러리는 쓰지 마.
CSV는 파일 선택 버튼으로 사용자가 열게 해 줘. 원본 파일과 값은 수정하지 마.
실제 관측 시각 그래프와 위상 그래프를 전환하고 curve_id별로 색을 구분해 줘.
m = -2.5 log10(F), 위상 = frac[24(JD-JD0)/P]를 사용해 줘.
P는 시간 단위로 입력하며 7.2를 초기값으로, JD0는 전체 최소 JD로 해 줘.
위상 비교에는 회차별 평균 m을 뺀 상대 등급을 표시하고 등급 축은 밝은 쪽이 위로 오게 해 줘.
관측점 수, 출처와 처리 방법을 표시해 줘. 자동 주기 탐색과 3D 기능은 다음 단계로 두자.
완료 후 파일을 열어 보는 방법과 확인할 항목을 알려 줘.

3. 내 흑점 측정 CSV 분석
첨부한 흑점 측정 CSV를 먼저 읽고 실제 열 이름과 단위를 알려 줘.
같은 흑점을 추적한 그룹별로 경도-시간 그래프를 그려 줘.
가장자리 제외 기준과 누락값을 확인하고, 선형 회귀 각속도에서 회합 자전주기를 구해 줘.
경도 증가 방향을 확인한 뒤 지구 평균 공전 보정을 이용한 항성 자전주기 근사도 비교해 줘.
측정값을 새로 만들지 말고 사용한 행·제외한 행·가정·오차 원인을 적어 줘.
그래프와 계산 과정을 읽을 수 있는 HTML 보고서로 저장해 줘.

4. FITS 헤더와 픽셀
이 프로젝트의 asteroid-1.fits를 읽어 줘.
HDU 목록과 OBJECT, DATE-OBS, EXPTIME, NAXIS, BITPIX, BSCALE, BZERO, BUNIT을 확인해 줘.
헤더에 없는 값은 추측하지 말고 미기재로 표시해 줘.
BSCALE·BZERO를 적용한 픽셀값과 화면 표시용 밝기 변환을 구분해 줘.
관측 시각·배열 크기·대상, 밝기 표시 방법을 설명하고 영상과 헤더를 볼 수 있는 교육용 화면을 만들어 줘.
원본 바이트는 보존하고 천구 북쪽 정렬이나 물리 단위 보정을 수행했는지도 밝혀 줘.

5. 주기 비교 버튼
지금 만든 광도곡선 도구에 P/2와 2P 버튼을 추가해 줘.
현재 주기를 기준으로 작동하고 두 봉우리의 높이와 관측 회차의 겹침을 비교할 수 있게 해 줘.
사용자가 비교한 주기·관측점 수·메모를 기록하고 CSV로 저장하게 해 줘.
관측 CSV는 그대로 두고, 입력 오류와 강도 F가 0 이하인 행은 설명해 줘.
“밝기 반복 주기와 자전주기가 같을까?”라는 탐구 질문도 넣어 줘.

6. 기존 3D 도구 수정
docs/shape-lab.js와 docs/shape-math.js의 팔라스 타원체 모형을 읽어 줘.
시선 각도 70도와 40도를 빠르게 선택하는 버튼을 추가해 줘.
각 조건의 a/b, c/b, 자전주기, 위상, RMS를 비교 기록할 수 있게 해 줘.
관측과 예측을 명확히 표시하고 고정한 변인·적합한 변인을 화면에 적어 줘.
DAMIT 문헌 메시가 앱에서 새로 복원한 결과로 보이지 않게 설명해 줘.
서로 다른 축비와 시선이 비슷한 광도곡선을 만들 수 있다는 질문을 유지해 줘.

7. 실제 교재와 연결
첨부한 강의계획서·교재 목차와 이 실습실의 활동을 비교해 줘.
원문에서 확인되는 단원과 학습 목표만 연결하고 해당 쪽이나 항목을 적어 줘.
태양 자전, FITS 측광, 팔라스 3D 모형 비교를 직접 연계와 확장 활동으로 구분해 줘.
한 활동을 골라 30분 수업 순서·탐구 질문·학생 제출물·평가 기준을 만들어 줘.
교재에 3D 형상 역산이 포함되어 있다고 임의로 쓰지 마.
확인할 수 없는 내용은 교수님 확인이 필요한 항목으로 남겨 줘.

8. 오류 수정
현재 index.html에서 아래 문제가 생겨.
실행 순서: [HTML 열기 → CSV 선택 → 주기 입력]
기대한 결과: [주기에 맞춰 위상 그래프 갱신]
실제 결과: [바뀌지 않음 / 빈 화면 / 오류 문구]
첨부한 화면과 관련 파일을 읽고 원인을 찾아 최소한으로 수정해 줘.
원본 관측 자료와 계산식은 보존하고 변경한 파일·원인·확인 순서를 알려 줘.
